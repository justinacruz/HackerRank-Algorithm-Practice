## Problems and Complexity

| Problem | Approach | Time Complexity | Space Complexity |
|---|---|---|---|
| Mini-Max Sum | Calculate total, minimum, and maximum | O(N) | O(1) |
| Birthday Cake Candles | Count candles with maximum height | O(N) | O(1) |
| Insertion Sort Part 1 | Shift elements to insert the final value | O(N) | O(1), excluding input |
| Binary Search | Search a sorted array by halving the range | O(log N) | O(1) |
| Mark and Toys | Sort prices and buy the cheapest toys | O(N log N) | O(N) |
